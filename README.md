# breast-cancer-logistic-regression

This project implements logistic regression from scratch, focusing on:

- Binary classification
- Loss function (logistic loss)
- Gradient computation
- Hessian matrix computation

## Dataset
The dataset contains features extracted from breast cancer cell images, used to classify tumors as malignant (1) or benign (0).

## Tasks implemented
- Scatter plot visualization of data
- Decision boundary plotting
- Loss function evaluation
- Gradient and Hessian computation
- Analysis of different parameter vectors

## Technologies
- Python
- NumPy
- Matplotlib
